# Smarcaz

## Install

In PowerShell:

```powershell
irm https://raw.githubusercontent.com/RaresCroicia/smarcaz-releases/main/install.ps1 | iex
```

The installer asks where to install (for the current user, no administrator prompt) and whether to add a desktop shortcut. An installed copy updates itself from the releases here.

The files aren't code-signed: when one is downloaded with a browser instead, Windows SmartScreen asks once (**More info → Run anyway**).
